# Sentra: мониторинг серверов и сети

Коробочный мониторинг для малого бизнеса. Ставится одной командой, сервер подключается одной командой, графики появляются через минуту. Без шаблонов, макросов и ключей PSK.

Версия 0.1 (этап 1 из ТЗ): Linux-серверы, CPU, память, диски, сеть, load average, обзор со статусами, графики за час, сутки, неделю и месяц.

## Установка коробки

Нужен Linux-сервер или VM (Ubuntu, Debian, CentOS/Alma): 2 vCPU, 2 ГБ RAM, 20 ГБ диска, доступ в интернет на время установки. Docker скрипт поставит сам.

```bash
curl -fsSL https://raw.githubusercontent.com/AbuBakrVu/Sentra/main/install.sh | sudo bash
```

Скрипт скачает код в `/opt/sentra`, определит IP сервера, соберёт и запустит коробку. В конце он покажет адрес панели и пароль администратора.

Если у сервера несколько адресов, укажите нужный явно:

```bash
curl -fsSL https://raw.githubusercontent.com/AbuBakrVu/Sentra/main/install.sh | sudo SENTRA_IP=192.168.1.10 bash
```

Откройте адрес из вывода скрипта. Браузер предупредит о самоподписанном сертификате: это нормально для локальной сети, подтвердите исключение. Войдите как `admin` и смените пароль в разделе «Настройки».

**Обновление:** запустите ту же команду ещё раз. Настройки, устройства и история графиков сохранятся.

Наружу коробка открывает только порт 443. VictoriaMetrics доступна только внутри Docker-сети.

<details>
<summary>Установка вручную</summary>

```bash
git clone https://github.com/AbuBakrVu/Sentra.git /opt/sentra
cd /opt/sentra
cp .env.example .env && nano .env     # IP коробки в SENTRA_PUBLIC_URL и SENTRA_CERT_HOSTS
docker compose up -d --build
docker compose logs sentra | grep пароль
```

## Подключение сервера

1. В панели откройте «Добавить сервер», скопируйте команду.
2. Выполните её на подключаемом сервере (нужны sudo, systemd и `curl`).
3. Сервер появится в панели сам.

Команда действует 24 часа, по ней можно подключить несколько серверов. Повторная установка на тот же сервер не создаёт дубль: сервер узнаётся по `/etc/machine-id`.

Как устроена безопасность подключения:

- В команде есть отпечаток ключа коробки. `curl --pinnedpubkey` скачивает скрипт и агент, только если ключ совпадает, поэтому подменить коробку в сети не выйдет.
- Агент запоминает тот же отпечаток и дальше разговаривает только с этой коробкой.
- После регистрации у агента свой постоянный ключ. Токен из команды больше не нужен.
- Агент только отправляет данные. Входящие порты на серверах открывать не нужно.

Полезное на сервере с агентом:

```bash
systemctl status sentra-agent
journalctl -u sentra-agent -n 50
sentra-agent collect          # разово показать, что собирает агент
```

Удалить агент: `systemctl disable --now sentra-agent && rm /usr/local/bin/sentra-agent /etc/systemd/system/sentra-agent.service && rm -r /etc/sentra`.

## Статусы на обзоре

| Статус | Когда |
| --- | --- |
| Нет связи | Агент не присылал данные больше 3 минут |
| Авария | CPU, память или самый заполненный диск выше 95% |
| Внимание | То же выше 85% |
| Ждём данные | Агент зарегистрирован, метрик ещё нет |

Пороги пока общие. Настройка порогов на каждое устройство, журнал проблем, порты и службы будут на этапе 2.

## Резервная копия

Всё состояние лежит в двух томах Docker: `sentra-data` (настройки, пользователи, устройства, ключ сертификата) и `vm-data` (метрики). Ключ сертификата важно сохранить: если он сменится, агенты перестанут доверять коробке и их придётся подключать заново.

```bash
docker run --rm -v sentra_sentra-data:/d -v $PWD:/b alpine tar czf /b/sentra-data.tgz -C /d .
```

## Разработка

```
cmd/sentra-server     точка входа сервера
cmd/sentra-agent      точка входа агента
internal/server      API, хранилище (SQLite), TLS, клиент VictoriaMetrics
internal/agent       сбор метрик Linux из /proc, регистрация, отправка
internal/proto       формат обмена агент ↔ сервер
web/                 интерфейс (React + Vite + uPlot), встраивается в бинарник сервера
```

Локальный запуск: запустите VictoriaMetrics на `127.0.0.1:8428`, затем `make run`. Панель будет на `https://127.0.0.1:8443`. Для правки интерфейса с горячей перезагрузкой: `cd web && npm run dev` (запросы `/api` проксируются на сервер).

Переменные окружения сервера:

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `SENTRA_LISTEN` | `:443` (в образе `:8443`) | Адрес и порт HTTPS |
| `SENTRA_DATA` | `/var/lib/sentra` | База, сертификат, ключ |
| `SENTRA_VM_URL` | `http://127.0.0.1:8428` | VictoriaMetrics |
| `SENTRA_PUBLIC_URL` | из адресной строки | Адрес для команды подключения |
| `SENTRA_CERT_HOSTS` | пусто | IP и имена в сертификате |
| `SENTRA_AGENTS_DIR` | `/opt/sentra/agents` | Бинарники агентов для скачивания |
| `SENTRA_ADMIN_PASSWORD` | случайный | Пароль admin при первом запуске |
